<!-- Python Quiz App -->

A simple and interactive Python Basics Quiz built using Python.
This program presents multiple-choice questions, checks user answers, provides explanations, and calculates a final grade based on performance. It’s perfect for beginners learning Python or anyone who wants to test their knowledge.

✨ Features

✔ Multiple-choice Python questions

✔ Automatic scoring

✔ Detailed explanations for wrong answers

✔ Grade calculation (A+ to F)

✔ Easy to run and beginner-friendly
